# Rose Mehal Marquee System — Frontend

React + Vite frontend for the Rose Mehal Marquee System.

## Pages included so far
- `/` — Landing page
- `/login` — Login / Register
- `/dashboard` — Customer dashboard
- `/admin` — Admin dashboard overview

These currently use sample/placeholder data. Backend (Express + Supabase) integration comes next.

## Setup

```
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```
npm run build
```

Output goes to the `dist/` folder, which is what gets deployed to Vercel.
